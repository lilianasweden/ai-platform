# AI Platform

Internal platform for building, deploying, and monitoring AI agents and ML models.

## Components
- **Agent Framework** — build and deploy AI agents
- **RAG Pipeline** — retrieval-augmented generation over internal knowledge bases
- **Vector Database** — Pinecone-backed semantic search
- **Model Serving** — REST API for Claude and internal models
- **Monitoring** — latency, token usage, and hallucination rate dashboards
